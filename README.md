## 📖 About

This repository holds my **C++ programming** work for the **Marvellous Logic Building Batch** — the object-oriented stage of the batch, building on the logic developed in C: classes and objects, constructors, encapsulation, inheritance, polymorphism, and generic programming.

Programs are added here assignment by assignment, in batch order, as the C++ stage progresses — each one compiled and tested before it is committed.

---

## 🗂️ Structure

```text
CPP_Programming/
│
├── README.md
├── LICENSE
├── .gitignore
├── assets/                 ← banner & footer artwork used in this README
│
├── Assignments/
│   ├── Assignment_1/       ← program1_1.cpp … program1_5.cpp
│   ├── Assignment_2/
│   └── …
│
└── Classwork/
    └── Day_NN/             ← classwork, added as the batch progresses
```

- **5 programs per assignment**, one folder per assignment: `Assignments/Assignment_N/`
- File naming follows the batch convention: `programN_M.cpp`

---

## ▶️ How to Compile & Run

```bash
g++ program1_1.cpp -o program1_1
./program1_1
```
